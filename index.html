SegCam

Transmita a webcam de qualquer dispositivo para outro, em tempo real.
Funciona entre redes diferentes. Sem instalar nada.

⚠ A câmera precisa de HTTPS (ou localhost) para acessar a webcam.
Hospede este arquivo em qualquer serviço estático (Netlify, Vercel, GitHub Pages…) e abra via HTTPS.
No celular, mantenha a tela ligada e o app em primeiro plano.
